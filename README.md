# Dr Quine

A quine is a computer program (a kind of metaprogram) whose output and source 
code are identical. The solution is an empty program, or one that reads it's 
own source file, this is not considered for this project.

This is a project done for 42Nice.

All exercises are done in C and then in assembly.

## Colleen

When executed it's output must be identical to the source. It must contain at least:

- a main function
- one comment inside the main
- one comment outside the program
- another function that gets called

## Grace

When executed it must write a file with it's source code called `Grace_kid.c`, 
which must be identical the the source. It must contain at least:

- no main decalred (no functions declared)
- exactly three defines
- one comment
- the program is run by calling a macro

## Sully

The program writes a file called `Sully_X.c` compiles and executes it, x is
so decremented untill it's 0.
